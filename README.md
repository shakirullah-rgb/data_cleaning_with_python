# Data Cleaning with Python:

A beginner-friendly **Data Cleaning practice project** using Python, Pandas, and NumPy.

##  Project Overview

This project demonstrates how to clean a messy student performance dataset and prepare it for further **data analysis or machine learning**.

The dataset contains intentionally introduced data-quality problems so that different data-cleaning techniques can be practiced.

##  Tools Used

* Python
* Pandas
* NumPy
* Jupyter Notebook / Google Colab
* CSV

##  Data Cleaning Steps

The project covers:

* Loading and inspecting the dataset
* Checking dataset shape and information
* Detecting missing values
* Removing duplicate records
* Cleaning column names
* Cleaning text and whitespace
* Standardizing categorical values
* Converting data types
* Detecting invalid values
* Handling outliers/invalid ranges
* Filling missing numerical values
* Filling missing categorical values
* Checking the cleaned dataset
* Exporting the final cleaned CSV

##  Dataset

The practice dataset contains approximately **1,000 original student records** with intentionally added duplicate and incorrect records.

Example columns include:

* Student ID
* Name
* City
* Gender
* Age
* Study Hours
* Attendance
* Assignment Completion
* Midterm Score
* Final Score
* Sleep Hours
* Internet Quality
* Result

##  Purpose

The main purpose of this repository is to practice **real-world data cleaning using Pandas and NumPy** and understand how raw data can be transformed into a clean, analysis-ready dataset.
